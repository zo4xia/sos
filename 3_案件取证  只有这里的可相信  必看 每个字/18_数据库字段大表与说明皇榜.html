皇榜说明：本表以本地 PostgreSQL backend_new 实际 schema 为准（2026-09-04 导出）。数据库列注释全为空，业务说明按甲方DOCX倒排工期表+系统设计语义补全。
核心商贸线路：election_proposals(审批通过) → pipeline → election_fiefs + election_fief_stages + positions + announcements → candidates + materials + candidate_reviews → 归档。
五角色：platform_admin(超管) / sub_admin(子管理) / editor(经办编辑) / reviewer(审核人) / candidate(参选人)。后台仅超管开账号，小程序注册绑死归属地。
