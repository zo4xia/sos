## 0. 一句话说清系统

一套**城厢区村居换届选举的内部管理系统（政务系统）**：平台超管给各归属地（村/社区，共 130+）开账号；归属地工作人员按 D 日倒排日程推进换届流程（公告、候选人材料审核、结果归档）；参选人通过小程序注册、提交材料、查看结果。**不是选民投票系统**，无线上投票。

## 4. 角色设计（2026-09-04 用户确认，以此为准，不沿用 backend-new 现有 org_admin/operator）

后台角色共 **5 类**，其中后台登录可用 4 类 + 参选人 1 类（不入后台）：

| 角色 | key | 归属 | 核心语义 |
|---|---|---|---|
| 平台超管 | `platform_admin` | 全局 | 全部权限：建组织、开账号、建/调角色权限、跨归属地 |
| 子管理 | `sub_admin` | 本归属地 | 可编辑+可审批；可管/删人员；**不可创建角色**（角色创建仅超管） |
| 经办编辑 | `editor` | 本归属地 | 可编辑、不可审批 |
| 审核人 | `reviewer` | 本归属地 | 可审批、不可编辑；**可审核公告** |
| 参选人 | `candidate` | 小程序端 | 仅查看+提交材料，不入后台登录 |

- **角色枚举收敛**：`memberships.role` 的 CHECK 约束改为 `('platform_admin','sub_admin','editor','reviewer','candidate')`（去掉 org_admin/operator，加 sub_admin）。
- 参选人只走小程序；后台登录仅放前四类。

## 5. 权限体系（2026-09-04 用户确认：必须可配置，不写死）

- **现阶段策略：暂时权限都给**（各角色先宽松放开，保证流程能用）。
- **结构必须可配置**：角色→权限点由数据承载，超管可在后台调整，后续按需收敛；**禁止做成不可变硬编码**。
- 落地：新增两张可配置表（见 §6），后端校验从 `role_permissions` 实时读权限点；前端登录拿到权限点列表渲染按钮。
- 权限点粒度（以后调整的维度）：建组织 / 建角色 / 开账号 / 管人员 / 提案编辑·审批 / 材料处理·审核 / 候选人维护·审核 / 公告编辑·审核·发布 / 查看本归属地数据。
- 现阶段默认 seed（宽松）：
  - 超管、子管理：后台全部动作
  - 经办编辑：编辑类 + 查看
  - 审核人：**审核类（含公告审核）+ 查看**
  - 参选人：仅小程序（提交材料 + 看结果）

## 7. 账号与注册分流（2026-09-04 用户确认，防串台从注册起内置）

- **小程序（参选人端）**：开放注册（自荐入口）。首次注册选择归属地 → 注册成功即**绑死归属地**（不可更改）；后续登录必须「归属地 + 账号 + 密码」三者匹配，归属地不符即登录失败。注册即分流为参选人（candidate）。
- **后台（政务端）**：系统是政务系统，**账号只能由平台超管开**，不开放任何公开注册/自行注册。后台账号由平台超管秘密创建和分配（初始密码 123456）。
- 依据：甲方 A-001（归属地+账号+密码三要素登录；后台不开放注册；账号由平台超管创建分配）+ 取证 07（身份权限隔离一级病灶）。
- backend-new 落点：登录模型天然支持（membership 绑 org + 三要素匹配）；需补「平台超管直接创建账号」接口（当前仅邀请制 `/admin/invitations`）；公开 `/auth/register` 仅保留给小程序参选人通道（role 强制 candidate、校验归属地 active）。

## 10. 甲方核心业务规则（A-001~A-008 摘要，详见取证目录）

- **A-001 身份**：两类组织（村/社区，130+）；登录三要素=归属地+账号+密码；后台不开放注册，账号由平台超管秘密创建分配（初始密码 123456）；角色至少含子管理、经办编辑、审核人。
- **A-002 概念边界**：参选人≠选民，无线上投票，禁止 voter/得票概念。
- **A-006 提案主链**：提案是后端业务起点 → 通过后自动生成归档/届次活动/D日Pipeline/公告集合；驳回可再编辑；通过产生且仅产生一套初始化产物。
- **A-007 公告与报名链**：公告由 Pipeline 日期驱动、模板预置正文、确认后定时发布；报名窗口到点开放；材料审核通过才进候选人池；区分自荐/组织推荐。
- **A-008 候选人管理**：候选人按届管理；线下送审+后台回填各轮结果；**多附件是硬约束**（可一键下载整套资料、舒适连续预览）；归档结构清晰可回溯。
